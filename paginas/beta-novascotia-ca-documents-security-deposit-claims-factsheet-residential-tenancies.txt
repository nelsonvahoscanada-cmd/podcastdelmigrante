Security deposit claims factsheet: Residential Tenancies
 Overview of how tenants and landlords can apply to the Residential Tenancies Program to file a security deposit claim.
 This document outlines what tenants need to know to have all or some of a security deposit returned. It also outlines what landlords need to know to keep some or all of the tenant’s security deposit for unpaid rent or damage.
 Information includes:
 what you should file
 when you should file
 what happens after you file
 how a decision is made
 tenant checklist
 landlord checklist
 resources
