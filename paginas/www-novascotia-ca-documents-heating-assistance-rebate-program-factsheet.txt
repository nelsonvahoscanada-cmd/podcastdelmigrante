Heating Assistance Rebate Program factsheet
 Overview of the Heating Assistance Rebate Program.
 The factsheet outlines the application period for the program and provides program details.
 Information includes:
 what the Heating Assistance Rebate Program is
 how to apply online
 where to pick up a paper application form
 how to check the status of your application
 contact information for Service Nova Scotia if you need to talk to someone about the program
 how to register for payment by direct deposit
